## Purpose

Although your CSSE coursework at UW Bothell provides a strong foundation in software development, preparing for a career as a mobile app developer requires additional experience with platform-specific development tools, application architecture, and mobile user interface design. Developing these skills before graduation allows you to build functional mobile applications and demonstrate your technical abilities to potential employers. The purpose of this report is to outline the best practices you can follow before graduation to prepare for a career as a mobile app developer.

## Developing Mobile App Fundamentals

### Learning Android Development Tools

Focusing on one mobile platform first allows you to develop a stronger understanding of mobile development before expanding into another platform. Employers value practical experience with platform-specific tools because it demonstrates your ability to develop applications beyond general programming assignments.

Begin with Android development using Kotlin and Android Studio. Follow Google's Android development tutorials to practice creating screens, handling user input, and navigating between screens [2].

### Developing User Interface Design Skills

Mobile applications depend on clear layouts and usable interactions. Employers value developers who can build applications that are both functional and easy to navigate.

Use Jetpack Compose to create consistent layouts, interactive components, and navigation between screens. Incorporate interface design throughout the development process rather than after the application is functional.

## Applying Mobile Development Practices

### Implementing Application Architecture

Separating user interface code from data management makes mobile applications easier to test and maintain [3]. Employers value this practice because professional applications require ongoing maintenance and feature development without disrupting existing functionality.

Organize your Android application into a UI layer and a data layer. Use Jetpack Compose and ViewModel to manage the interface and its state, Retrofit to retrieve data from REST APIs, and Room to manage local data storage. ### Testing and Debugging Applications

Identifying problems early makes them easier to isolate and fix before applications become more complex. Employers value developers who can deliver reliable applications and prevent existing features from breaking.

Test each feature as you build it. Use the Android Studio emulator to verify user interactions and Logcat to identify errors. Test unsuccessful API requests and invalid user input alongside successful interactions.

## Developing a Professional Portfolio

### Building Mobile Applications

Gürkan Atay, a staff software engineer at OfferUp, recommends developing a complete application that solves a real problem and goes beyond an initial working demo [4]. Completed applications demonstrate your ability to apply technical knowledge independently.

Build a task management application using Kotlin and Jetpack Compose. After completing it, develop a recipe application that retrieves recipes from a REST API and stores saved recipes locally. Test the application and gather feedback from users.

### Documenting Development Projects

Well-documented projects allow employers to evaluate your technical abilities, development decisions, and contributions without examining the entire codebase.

Publish both applications to GitHub. Include README files containing each application's purpose, technologies, major features, architecture, setup instructions, and screenshots.

## Gaining Professional Experience

### Pursuing Mobile Development Internships

Internships provide experience working with existing codebases, development teams, and professional software development practices. This experience helps demonstrate your ability to contribute to a professional development environment.

Search Handshake for Android development internships. Prioritize positions involving Kotlin, Android Studio, and mobile application development. Include your completed Android projects when applying.

### Building Professional Connections

Collaborative development requires communicating technical decisions, dividing responsibilities, and responding to feedback.

Participate in university hackathons and contribute to a shared GitHub repository using branches, pull requests, and code reviews. Connect with participating developers to maintain professional relationships beyond the event.

## Preparing for Mobile Development Careers

### Tailoring Job Applications

Connecting your project experience to specific job requirements helps employers recognize how your skills align with the position.

Identify Android developer positions that require Kotlin, Jetpack Compose, and REST API integration. Highlight relevant features from your completed applications in your resume and include links to their GitHub repositories.

### Preparing for Technical Interviews

Mobile development interviews require you to explain technical decisions and demonstrate your understanding of application functionality.

Practice demonstrating your completed Android applications. Explain how data moves between the UI and data layers, how your application handles unsuccessful API requests, and why you selected its architecture.
